# Wireshark Traffic Analysis Lab

## Project Overview

This project demonstrates how to capture and analyze network traffic using Wireshark.

## Objective

Capture packets generated by web browsing activity and analyze HTTP communications.

## Environment

- Windows 11
- Wireshark
- Google Chrome

## Tasks Performed

1. Started Wireshark packet capture.
2. Selected Ethernet0 interface.
3. Generated traffic by visiting uCertify.
4. Captured network packets.
5. Applied HTTP filters.
6. Examined packet details.
7. Followed the HTTP stream.
8. Saved the capture file.

## Skills Demonstrated

- Packet Capture
- Network Analysis
- HTTP Traffic Inspection
- TCP Stream Analysis
- Wireshark Filtering
- Troubleshooting Network Traffic

## Findings

- Applied the `http` display filter to inspect HTTP traffic.
- Examined a GET request to `oneocsp.microsoft.com` with a path beginning `/ocsp/`.
- Followed the HTTP and TCP streams and observed an `HTTP/1.1 200 OK` response with content type `application/ocsp-response`.
- The inspected exchange was with a Microsoft host; it does not establish that the packets came from the uCertify website.

## Lab Context

This was a guided uCertify packet-capture exercise completed in the provided Windows lab environment.
## Key Takeaways

This lab improved my understanding of packet capture, protocol analysis, and network troubleshooting using Wireshark.
